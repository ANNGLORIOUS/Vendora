# Frontend scaffold

This folder contains a Vite + React + TypeScript scaffold for the Vendora frontend.

Structure highlights:
- `src/pages` - page routes and views
- `src/components` - UI components and layout
- `src/services` - API client and query client

To run locally:

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
# Vendora Frontend
